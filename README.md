A student organizer designed to streamline the management of academic and daily life tasks. It provides a structured and user-friendly environment for tracking assignments, organizing responsibilities, and maintaining productivity.

##  Features

* **Task Management:** Add, update, and track both academic and personal tasks
* **Task Locking:** Option to lock important tasks for better visibility
* **Activity History:** Maintains a record of user actions
* **Recycle Bin:** Safely stores deleted tasks for easy restoration
* **User-Friendly Interface:** Clean and intuitive design

##  Objective

To help students improve time management, stay organized, and manage multiple responsibilities efficiently in one place.

##  Usage

1. Add tasks (academic or personal)
2. Organize and prioritize them
3. Lock important tasks if needed
4. Track progress through history
5. Restore deleted tasks from the recycle bin
